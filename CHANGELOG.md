# CHANGELOG

## [1.0.0] - 2026-11-10

### ✨ Features Iniciais
- ✅ **Autenticação**: Login/Registro com email e username
- ✅ **Chat em Tempo Real**: Mensagens instantâneas via Firestore
- ✅ **Fotos**: Envio de imagens com suporte a visualização única
- ✅ **Emojis**: Seletor completo de emojis
- ✅ **Soft Delete**: Exclusão de mensagens e conversas sem recuperação
- ✅ **UI Responsiva**: Interface adaptável para desktop, tablet e mobile
- ✅ **Privacidade**: Acesso restrito aos participantes do chat

### 🛠️ Stack Tecnológico
- React 18
- TypeScript
- Vite
- Firebase (Auth, Firestore, Storage)
- emoji-picker-react
